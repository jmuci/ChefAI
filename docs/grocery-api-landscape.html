Pocket Chef — Product Research

Grocery API Landscape

Can Pocket Chef push a meal plan's grocery list directly into a supermarket cart, without routing through Instacart the way SideChef does?

Researched Aug 2026. Findings are point-in-time — retailer partner programs and API terms change; re-verify before committing engineering time.

TL;DR — Going direct to Safeway to avoid Instacart isn't achievable today: Safeway/Albertsons' own pickup and delivery fulfillment runs on Instacart's infrastructure under a 2024 nationwide partnership, so there's no separate "direct" rail to integrate with. Kroger — City Market's parent — is the one genuinely self-serve, contract-free starting point: their public Cart API supports adding items to a real user's cart today with no business agreement required.

Per-retailer findings

Instacart Developer Platform / Connect Partner-gated

A real, actively-developed API (Connect, plus 2026 AI-agent/MCP tooling and the OpenAI/ChatGPT shopping integration) — but not self-serve. Access requires a partner agreement, per-call pricing isn't published, and the revenue model is affiliate/commission-based (industry marketplace take rates run roughly 5–15%).

Building on Instacart's own API doesn't remove the "Instacart tax" — it likely makes Pocket Chef another affiliate inside the same commission structure SideChef presumably already uses.

Sources: Instacart Developer Platform · Connect APIs docs · Conversion & affiliate payments

Albertsons / Safeway No public cart API

No public developer or cart API exists for Albertsons banners. Safeway's pickup and delivery — including the newer "Rapid" 30-minute delivery — is powered by Instacart under a nationwide partnership expansion announced in 2024. There is no separate, direct Safeway fulfillment path to integrate with instead.

The only public Albertsons API is for their ad/retail-media network (Albertsons Media Collective) — campaign performance data, unrelated to shopping carts.

Sources: Instacart/Albertsons partnership expansion (2024) · Albertsons Media Collective API (ad data, not carts)

Kroger Self-serve, partially open

City Market's parent company. Kroger runs a public developer portal with a real Cart API: product lookup plus add_to_cart (with PICKUP or DELIVERY modality), authenticated via per-user OAuth2, rate-limited to 5,000 calls/day. Adding items works today with no business contract.

The catch: the public tier can add items but cannot remove them. Full cart management requires Kroger's gated Partner API, which does require a business contract.

Sources: Kroger Cart API (public)

Recommended rollout: three tiers

Tier 0 — Plain grocery list

No store integration

Aggregate and dedupe ingredients from a meal plan into a checklist the user shops with manually, at whichever store they choose. Zero external API dependency, ships against the existing meal-plan data model, matches the grocery-list feature already described in the README. Do this first — it's pure win, no new risk.

Tier 1 — Assisted, one item at a time

Deep-link into the retailer's own app/site

For each grocery item, open the retailer's own app or website pre-loaded with a search for that item, so the user taps "Add to cart" themselves inside their official app. This is legitimate — it's automating a search, not scraping or driving their UI — and needs no store partnership. Requires per-retailer research to confirm each app/site supports a query-param search deep link before committing to it.

Tier 2 — True one-tap cart add

Where the public API allows it

For City Market (Kroger), skip Tier 1 entirely: call the public add_to_cart API directly with the user's OAuth token. Real differentiator versus Safeway, where Tier 1 is the practical ceiling unless/until a formal Instacart or Albertsons partnership is pursued.

Explicitly out of scope Don't fake Tier 2 for Safeway via scraping or headless-browser automation of their checkout. That crosses into ToS-violation / bot-automation territory — fragile, and not something to build even as a stopgap.
