## Top issues (fix first)
1. **API-1 (S1)** — fresh user's pull stalls at ~110 seed recipes (µs vs ms cursor); a reinstall or new device never gets the user's own recipes. Production may be affected.
2. **API-16 (S1)** — creators' emails exposed to anyone who can see a public recipe, including anonymous callers; sitemap lists all public recipe ids.
3. **LOGIC-1 (S1)** — ingredient quantity ≥ ~1.8e306 throws in the formatter/shopping list; editor accepts pasted `1e307`, so the screens crash on every open.
4. **LOGIC-2 / SCRAPER-2 (S2)** — NaN/Infinity ingredient quantity (editor paste or scraped "NaN g flour") makes every sync fail / crashes the import save.
5. **SCRAPER-1 (S2)** — StackOverflowError escapes `RecipeHtmlParser.parse` on deeply nested JSON-LD.
6. **LOGIC-3 (S2)** — session returns after logout when a token refresh is in flight.
7. **UIA-1 (S1, dev-only)** — debug builds default to production; `pm clear` re-arms it. Suggest defaulting debug to LOCAL.
8. **UIA-2 (S2)** — Login is unusable in landscape (buttons clipped, dev options drawn over password).
9. **API-3 / API-4 / API-8 (S2)** — push with empty body → 500; one U+0000 recipe poisons the whole batch (409 forever); huge `since` → 500.
10. **UIB-2 (S3)** — last step's timer button hidden under the Edit FAB.
11. **UID-10 (S2, round 2)** — an imported/created recipe that uses a home-sidecar ingredient never syncs (server rejects `INGREDIENT_NOT_FOUND`) while the UI says "Synced"; sidecar ids are `nameUUIDFromBytes` and marked SYNCED (`SidecarMapper.kt:64-75`). Also UID-11 (undeletable tombstone loop) and UID-12 (new ingredients silently dropped server-side, #101).
12. **PLANS-2 / PLANS-6 (S3, round 2)** — deleting a recipe in a plan leaves an unremovable dead slot ("Recipe Not Found! This was not supposed to happen"); a dietary restriction is silently dropped when no tag matches (Vegan plan returned chicken and parmesan pasta).
Also worth early attention: SCRAPER-9 (any URL scheme reaches `draft.imageUrl`, loaded by Coil without the SSRF guard), LOGIC-5/6 (account upgrade and pull handlers can lose stars/edits/tombstones), API-17 (PUBLIC→PRIVATE never reaches devices that already pulled it).
